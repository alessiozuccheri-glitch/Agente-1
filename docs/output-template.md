# Formato output standard

Ogni consegna dell'agente segue **sempre** questa struttura a 11 punti (come da brief).
Serve a rendere il lavoro leggibile, comparabile e approvabile a colpo d'occhio.

```markdown
## [Nome prodotto] — Scheda operativa

### 1. Opportunità trovata
[cosa è stato individuato e dove]

### 2. Analisi mercato
- Domanda stimata: [valore] — fonte: [eRank/...] — [VERIFICATO | IPOTESI_DA_VALIDARE] — data
- Concorrenza: [n. listing / qualità top 10]
- Saturazione: [bassa/media/alta]
- Trend: [su/stabile/giù] — fonte: [Google/Pinterest Trends]
- Margine potenziale: [%/valore]

### 3. Punteggio prodotto
Totale: [X.X]/10 (soglia 8). Dettaglio criteri: [tabella scoring]

### 4. Strategia prodotto
[posizionamento, differenziazione, varianti, bonus]

### 5. File da creare
[lista file + formato + naming]

### 6. Mockup necessari
[hero, lifestyle, detail, benefit, what's-included, thumbnail, pin, ads + prompt]

### 7. SEO Etsy
- Titolo (≤140): [...]
- 13 tag: [...]
- Descrizione: [...]
- Categoria: [...]
- Keyword primarie/secondarie: [...]

### 8. Prezzo consigliato
[prezzo + sconto lancio + bundle + upsell/cross-sell]

### 9. Piano pubblicazione
[checklist pre-pubblicazione + richiesta approvazione 🧑]

### 10. Piano traffico
[Pinterest + TikTok/IG + Etsy Ads (budget test) — organico prima, paid dopo]

### 11. Prossima azione consigliata
[la singola cosa da fare adesso, con eventuale gate umano]
```

## Regole di compilazione
- **Nessun campo inventato.** Se manca un dato reale → `IPOTESI_DA_VALIDARE` + come ottenerlo.
- **Una sola "prossima azione"**: chiara, eseguibile, con eventuale gate.
- I numeri hanno sempre **fonte + data**.
